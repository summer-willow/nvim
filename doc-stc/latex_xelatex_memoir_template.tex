\section{연구 배경}
질문하신 대로 매직 커멘트(\texttt{\% !TEX program = xelatex}) 위에 일반 설명 주석이 있어도 에디터는 정상적으로 엔진을 인지합니다. 

현재 이 문서는 \texttt{XeLaTeX} 엔진을 통해 컴파일되고 있으며, \texttt{fontspec} 구조를 거쳐 영문은 고전적이면서 미려한 \textit{Latin Modern Roman}으로, 한글은 시스템 기본 명조/고딕 계열로 깨짐 없이 깔끔하게 조판됩니다. 이전에 발생하던 \texttt{microtype} 관련 폰트 패치 경고도 말끔히 해결됩니다.
