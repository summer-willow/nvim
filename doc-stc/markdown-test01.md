# 마크다운 LaTeX 스니펫 연동 테스트

이 파일은 마크다운 문서입니다. 여기서도 Tree-sitter 가 수식 구역을 정확히 발라내는지 테스트합니다.

## 1. 수식 바깥 구역 (Markdown 영역)
* 아래 빈 공간에 `ff`를 입력해 봅니다.
* **예상 결과:** 마크다운 본문이므로 자동 변환 없이 그냥 `ff` 텍스트가 입력됩니다.



## 2. 마크다운 내 인라인 수식 구역 ($...$)
* 아래 달러 기호 사이 커서 위치(`|`)에 `ff`를 입력해 봅니다.
* **예상 결과:** 마크다운 파일임에도 불구하고, 내부 수식 영역을 감지하여 `\frac{ }{ }`로 **자동 트리거**가 발동해야 합니다!
